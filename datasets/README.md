# Dataset workspace

This directory is the single data root for the project. Upstream model
submodules contain code only; source releases are stored here and referenced by
the canonical pipeline.

## Directory ownership

| Path | Contents | DVC policy |
|---|---|---|
| `raw/` | Original inputs: ADMET, Sangster logP, MST-NMR, NMRexp, NMRTrans, NMRGym, SimNMR-PubChem | Source directories pinned by `.dvc` files; downloadable from public upstream releases |
| `canonical/` | One schema-v2 Parquet per source split used by the pipeline | Cached and locked, `push: false` |
| `intermediate/` | Rich merges, overlap-transfer outputs, pre-clean benchmark, filtered train, and removal audits | Cached and locked, `push: false` |
| `cleaned/` | Final train/test, SimNMR, NMRGym, ADMET cohorts, molecular-property Parquets, and analytics | Locked by DVC and released publicly on Hugging Face |

`datasets_old/` is an ignored local archive and is not a dependency of the DVC
DAG. Do not use it as an implicit input or copy its counts into reports for a
new run.

## Raw sources

Each source directory is represented by `datasets/raw/<source>.dvc`. Those
pointers contain the exact DVC hashes; [sources.yaml](raw/sources.yaml) adds only
stable human-readable provenance, licence where known, released filenames, and
the converter or consumer. Keep secrets and machine-specific paths out of both.

The ADMET raw directory contains all 22 downloaded TDC endpoints, while the
production stage uses Ames, LD50 Zhu, AqSolDB solubility, and AstraZeneca
lipophilicity from TDC, plus the separately tracked Sangster logP workbook.

Download all raw inputs from their public upstream releases with:

```bash
source ~/.bashrc
nmr-env main
scripts/data/download_raw_datasets.sh all
```

The downloader uses pinned source revisions, writes the exact paths consumed by
the DAG, and checks the result against the committed `.dvc` pointer. It never
overwrites a completed source. SimNMR is assembled one part at a time and an
interrupted transfer can be resumed without keeping a second 400 GB copy.

To replace a raw release intentionally, update only its source directory, run
`dvc add datasets/raw/<source>`, and review both the changed pointer and
`sources.yaml`. A raw update invalidates downstream stages through the DAG; do
not modify canonical files by hand to compensate.

## Pipeline outputs

The root [dvc.yaml](../dvc.yaml) is generated by
[`scripts/data/generate_dvc_pipeline.sh`](../scripts/data/generate_dvc_pipeline.sh).
The large rebuildable canonical, intermediate, and audit files declare
`push: false`. This prevents ordinary remote uploads but does not disable the
DVC cache or run cache. Final files and compact reports use normal DVC output
policy for the private maintainer cache; public releases are uploaded to
Hugging Face separately.

A successful full run produces:

```text
cleaned/
├── README.md
├── ANALYTICS.md
├── rich.parquet
├── test_benchmark.parquet
├── simnmr.parquet
├── nmrgym.parquet
├── {rich,test_benchmark,simnmr,nmrgym}_mol_properties.parquet
├── *_report.json
├── admet/
│   ├── preparation_report.json
│   └── {ames,ld50_zhu,solubility_aqsoldb,lipophilicity_astrazeneca,sangster_logp}/{train_val,test}.{csv,parquet}
└── analytics/
```

`README.md` is the Hugging Face data card and `ANALYTICS.md` is its manual
analytics index. They live outside the DVC-owned `analytics/` directory so a
pipeline reproduction does not overwrite editorial release documentation.

Every maintained stage also writes a compact JSON report with `stage`,
`inputs`, `outputs`, and `counts`, plus `details` only when a useful breakdown
exists. SimNMR additionally keeps a row-level JSONL rejection audit because the
individual source rows that failed chemical-metadata derivation are needed for
debugging.

## Reproduction and publication

```bash
dvc dag
dvc repro
```

`dvc repro` materializes stale prerequisites automatically. Pipeline commands
use quiet mode but retain one progress bar and real errors for each stage.
After a successful reproduction, commit `dvc.lock` together with the relevant
code, `dvc.yaml`, `params.yaml`, source pointers, manifest changes, and
documentation.

The public release channel is
[Hugging Face](https://huggingface.co/datasets/niccogreek/nmr-canonical-cleaned):

```bash
hf upload niccogreek/nmr-canonical-cleaned datasets/cleaned . \
  --repo-type dataset \
  --exclude .gitignore \
  --exclude "*_processor_compatibility.json"
```

Nebius Object Storage is only a private maintainer cache. Authorized project
machines may still use `dvc push` and `dvc pull` to reuse cached objects, but
public users reproduce from upstream raw downloads and do not need Nebius
credentials.

Do not commit Parquet, LMDB, pickle, CSV, analytics images, or DVC cache files
to Git. Do commit `.dvc` pointers, `dvc.yaml`, `dvc.lock`, `params.yaml`,
`sources.yaml`, README files, and processing code.

The scientific meaning of the sources and the historical measured counts are
in [Datasets](<../contex/Datasets.md>) and
[Dataset Analysis](<../contex/Dataset%20Analysis.md>). The exact processing
rules are in [Dataset Filtering and Processing](<../contex/Dataset_Filtering_and_Processing.md>).
